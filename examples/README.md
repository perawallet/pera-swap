# Examples

| Example            | What it shows                                                                   |
| ------------------ | ------------------------------------------------------------------------------- |
| [`react`](./react) | Widget URL, direct iframe, custom UI on the Swap API, and parent-signer signing |

Examples are pnpm workspace packages that use the library from this repo
(`workspace:*`), so changes to `src/` show up immediately.

```bash
# from the repo root
pnpm install
pnpm example:dev
```
