# Examples

| Example            | What it shows                                                                   |
| ------------------ | ------------------------------------------------------------------------------- |
| [`react`](./react) | Widget URL, direct iframe, custom UI on the Swap API, and parent-signer signing |

Examples are pnpm workspace packages that use the library built from this repo
(`workspace:*`). `pnpm example:dev` builds it first; run `pnpm dev` alongside to
rebuild on every change to `src/`.

```bash
# from the repo root
pnpm install
pnpm example:dev
```
